# 随心调色：图片编辑与 AI 接入需求

更新：2026-10-30。此文为用户要求的整体需求和接手清单；实际状态以每项勾选与 `HANDOFF.md` 为准，未勾选不代表已实现。

## 目标

保留照片为中心的原生 macOS 工作区，以一个对话入口和易发现的图片工具完成调色、去除、抠图、画质提升和生成式编辑。用户既可自行选择工具，也可用自然语言描述，系统不得把“看图调参数”和“直接生成新图片”混成一种能力。

## 2026-10-30 评审调整（以本节为准，覆盖下文与之冲突的条目）

用户要求复核上一轮的构思并按调整后的方案逐项施工。调整与理由：

1. **不做「AI 调整 / AI 修图」两个模式开关。** 用户不该先判断自己的要求属于哪种技术。只保留一个对话：能用参数做的直接做；需要生成新像素的（移除大物体、替换、添加、换背景等）先在对话里出一张确认卡，写明发给哪家、发送什么、预计费用、结果是新图，用户点「生成」才调用。没配出图服务时卡片给设置入口。
2. **生成结果当作照片的新版本，不是“不可还原的另一类东西”。** 做法同修复：生成图存进工程并替换这张照片的源图，原图和前一版保留，可撤销、可前后对比；之后照样能在新图上拉滑块、套风格。导出、保存工程、重开都按版本走。
3. **出图服务先接即梦（火山方舟 Seedream），Gemini 放后。** 用户国区 Google 账号出图接口被封、还要代理；即梦用户已在用。各家适配器分开写。真实调用会收费，先用本地模拟服务跑通全流程，真实调用前问用户；即梦对真人脸有审核限制，要实测记录。
4. **抠图改用 macOS 自带的主体抠图（Vision 前景分割，照片 App 长按抠图同款）。** 发丝边缘质量远好于现在借用的区域分割模型，不下载模型、无商用授权问题、支持系统 14+。点选哪个主体就抠哪个；系统找不到主体或点在背景上时如实提示。抠图和导出一样是“产出新文件”（另存透明 PNG，原照片不变），不作为照片上的一步编辑存进工程。
5. **图片工具不藏在菜单里。** 画布工具栏直接放「移除」「抠图」「画质」三个按钮，少一次点击、一眼可见。
6. **对话多方案上限从 12 改为 4。** 超过 4 个缩略图难以比较，每个方案都要渲染预览，多了只是慢。
7. **选区不自动消失。** 有选区时始终保留细轮廓线，编辑选区时才显示填充；“显示 2 秒后隐藏”会让人不知道选区还在不在。
8. **替换、添加内容只走生成式流程（第 1 条的确认卡）**，不另做本地「替换」按钮。
9. 风格分组名：用户 2026-10-30 定为「轻微调整 / 风格化调整 / 我的风格」（取代 10-28 的「自然 / 出片」）。

## 2026-10-30 第二轮：选区加减、统一设置、AI 改图面板（用户看效果图 `output/mockups/image-edit-20261030/` 后确认）

用户反馈：选区画完不能加减；出图服务找不到入口，调色和改图的逻辑分不清。整体理成「调色 / 改图 / 对话」三层、一个设置窗口：

| 层 | 做什么 | 结果 | 入口 |
|---|---|---|---|
| 调色 | 风格、光线颜色质感、局部 | 参数，随时可拉可撤 | 右栏「调整」 |
| 改图 | 选区、移除、AI 改图、抠图、画质 | 改像素，生成新版本，可撤销 | 画布工具栏按钮 |
| 对话 | 一句话 | 能调色直接调；要生成先出确认卡 | 右栏「对话」 |

- [x] 选区可多笔加减：`SelectionPart`（画笔／套索／点选物体／方框，`subtract`），`RemovalOperation.parts`；引擎 `shape_mask(parts=)` 按顺序合成；选区里的点选允许大片区域（移除杂物仍拒绝）。画布浮动工具条（选法、添加／减去、按住 ⌥ 临时减去、笔刷、撤销一笔、清除）；选区、移除、AI 改图三页共用一份选区，换功能不丢（抠图除外）；`/selection-overlay` 叠出合成后的真实样子；已保存的手动选区可「编辑选区」继续加减。
- [x] 统一设置窗口 `SettingsSheet`（菜单「设置…」⌘,、对话页齿轮、AI 改图面板、确认卡都打开它）：「对话和看图」「AI 改图」两页，各自显示已配置／未配置／能看图。
- [x] AI 改图面板 `AIEditPanel`：改哪里（整张／只改选区，有选区自动切到只改选区）→ 想改成什么（示例一键填）→ 发给谁（未设置时黄色提示＋去设置）→ 生成；结果在对话里留记录可撤销；「这张照片的版本」可临时在画布上查看旧版本（不改照片）。
- [x] 发给出图服务的是**不带调色的原片**（保留移除杂物等修改），生成图作为新版本后用户的调色照常套用，避免调色叠两次。只改选区时在**原尺寸**上只替换选区（羽化），选区外像素不动（有测试）。
- 工具栏七个按钮：对比、原图｜选区、移除、AI 改图、抠图、画质；窗口窄时自动只显示图标（悬停看名字）。
- 区域轮廓先清理再描边（填小洞、去碎点），否则水面波光会出现大量碎圈。
- 仍需用户：即梦真实出图（密钥＋收费）；整套交互的亲手试用（我只能截图，不能拖拽）。

## 已确认需求

1. 对话中已执行操作只显示简短结果与撤销；参数明细默认折叠，点击查看。
2. 用户可让 AI 给出多个方案，直接展示缩略图；选择后应用，参数调整可撤销。维持原图与已有编辑，不能拿旧结果覆盖后续修改。
3. 对话应区分“AI 调整”（本地参数与区域，可继续滑动）与“AI 修图”（远端返回新图片，可能改变细节/尺寸，不可还原成参数）。不自动跨方式上传或生成。展示模型、作用照片、发送内容和潜在费用；原图始终保留。
4. 用户明确需要抠图：选择人物或物体后可预览边缘，生成透明背景 PNG，保留原照片；不得把普通矩形选区声称是准确抠图。可使用现有可靠分割能力，低置信度时需要提示、允许修边；不增加未获授权的模型下载或依赖。
5. 修复、画质和抠图归入容易发现的图片编辑工具，画布保持主要空间；右侧呈现当前工具的设置，不做多套互相矛盾的入口。现有修复预览、保留和撤销不能退化；画质降噪/放大仍可用于批量。
6. 选区是独立的共享状态，可由画笔、套索、点选、方框建立；选择后可按能力进入局部调整、移除、替换或抠图。换操作不应无故丢失选区；先显示一次选区约 2 秒，再隐藏，手动显示按钮显眼。
7. 提示词按操作和模型能力决定：移除/抠图无需强制输入；替换或添加须知道目标内容，可输入文字或明确选择现有替代素材；有的服务允许空提示词时可用明确的工具默认语义，不能把无内容的替换伪装为完成。必填、可选、无需提示应清楚标记；只呈现与操作相关的字段。
8. API 设置以服务商和能力表达：密钥是否保存、模型、连接测试与实际能力测试分开；连接成功不等于模型支持看图/出图。用文字和状态图标表达，未知能力标待验证；密钥进本机钥匙串，不入文件/聊天/日志。不要把获取的所有模型都标成支持某项能力。
9. 对接支持图像编辑的服务，包括 Nano Banana/Gemini 与即梦/火山引擎。先核实其实际 API、认证、支持的图片输入/输出、数量、格式、分辨率、费用和地域；不同 API 适配器分开，不能假定所有服务均为 OpenAI 兼容或密钥可通用。用户的真实密钥和照片不得被用于未授权测试；公开样片配模拟服务先验。
10. 源图、参数式调整与 AI 生成文件需明确持久化：保存工程后能恢复所选结果及历史的必要依赖，导出不覆盖原文件；缺文件时提示，不能默默使用临时会话路径。生成图标签需清楚，支持比较和撤销。

## 拟议界面

- 画布顶部保留原图和对比；把“修复、画质”整合成“图片工具”入口，菜单或工具栏显示「移除」「抠图」「画质」；所选工具内容出现在右侧。避免遮挡画面和横向堆积。
- 对话顶部显示「AI 调整 / AI 修图」及当前模型；输入框保持一致。模型不具备所需能力时给清晰的设置入口，不伪装已支持。
- 选区建立后出现操作入口：局部调整、移除、替换、抠图。使用前保留选区；替换条件不完整时说明缺什么。
- 结果在对话中显示缩略图与名称，明细折叠；可比对、选择、撤销，生成结果与参数方案标识不同。

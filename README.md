# 随心修图 · SuiTone

用自己的话和 AI 对话修图，也可以手动调整光影、颜色和局部区域。导入时保留原照片，调整可继续编辑、撤销和导出。

> **当前为开发版。** 尚未提供可在其他 Mac 独立安装的发行包；运行时、模型授权、签名及更新流程仍在验证。下面的说明记录现有功能和配置方式，不代表所有平台或服务已经实测。

## 可以做什么

- **对话调整**：描述你的想法，AI 分析照片并返回可继续调整的参数；可以使用本机账号或自备 API。
- **手动调色**：调整光线、颜色、质感，选择风格或参考图；导入时不会自动修改照片。
- **局部选区**：画笔、套索、点选或方框选择区域，支持添加和减去。
- **移除、抠图和画质**：预览移除杂物、保存透明主体 PNG，以及进行降噪和放大。
- **AI 改图**：配置出图服务后修改整张照片或选区；结果作为新版本，可以撤销。
- **多张照片**：在照片条中按住 Command 选择多张；风格缩略图以所选第一张为例，调整作用于所选照片。

## 系统与当前安装状态

当前开发环境为 macOS 14 或更新版本，实际开发机为 Apple 芯片。Intel、干净系统和不同版本 macOS 尚未完成发行验收。当前仓库没有可供普通用户直接安装的独立安装包，也没有已验证的 AI 一键安装命令；请勿将开发机生成的 `dist/SuiTone.app` 复制到其他电脑后当作可用安装包。

### 让 AI 协助配置对话工具

随心修图的发行安装包还未准备好。已经在开发环境运行应用的用户，可以把下面的话发给自己使用的 AI 助手，请它协助配置本机对话工具：

> 请帮我检查这台 Mac 是否安装并登录了 Codex、Claude Code 或 CodeBuddy Code。我想在随心修图里使用其中一种。请参考各自的官方安装文档，先说明需要安装什么，再按我的选择操作；登录由我自己完成。不要读取或发送我的密钥。配置完成后告诉我在随心修图设置中的选择步骤，并说明是否已经实际测试看图。

AI 助手安装或登录第三方软件前，仍应确认所需权限和服务费用。这个提示词只用于配置对话工具，不会安装尚未发行的随心修图。

发行前需要准备独立 Python 运行环境、依赖和模型，核对各组件的许可和再分发条件，并测试签名、安装及更新。详细清单见 [发行准备](docs/RELEASE_READINESS.md)。

## 开始使用

1. 启动应用后导入照片。照片默认保持原样。
2. 在右侧「调整」中使用滑块或风格；多选时留意照片条和作用范围提示。
3. 想用文字修图时，打开「对话」，在设置中选择 AI 服务，并在发送照片前确认授权。
4. 若需要换背景或添加内容，打开「AI 改图」，选择整张或先画选区，填写要求并配置出图服务。
5. 使用「保存调整记录」保存工作；使用「导出」生成新照片，不覆盖原文件。

## 配置 AI 对话

在应用菜单「设置」→「对话和看图」中选择服务。对话需要支持图片输入的模型；首次使用每个服务时，应用会提示预览图发送到哪里。照片预览和你的要求会发送到所选服务，请自行确认适合上传的照片。

### Codex

1. 安装并登录 Codex，确认订阅和当前账户支持使用。可参考 [OpenAI Codex 指南](https://developers.openai.com/codex/)。
2. 在「对话和看图」的本机账号中选择 Codex，点击「使用这个」。
3. 同意发送照片预览后，用文字描述想调整的内容。CLI 未安装或未登录时需先完成对应配置。

### Claude Code

1. 按 [Claude Code 官方安装文档](https://code.claude.com/docs/en/setup)安装并登录 Claude Code，确认账户及额度可用。
2. 在「对话和看图」中选择 Claude Code，点击「使用这个」。
3. 同意发送照片预览后开始对话。安装应用本身不等于已经完成命令行登录；登录和额度问题需在 Claude Code 中处理。

### WorkBuddy / CodeBuddy

1. 仅安装或登录 WorkBuddy 桌面版不代表 CodeBuddy 命令行已经登录。按 [CodeBuddy 官方快速指南](https://www.codebuddy.cn/docs/cli/quickstart)安装 CodeBuddy Code，并使用与 WorkBuddy 相同的账号完成命令行登录。
2. 在「对话和看图」中选择「WorkBuddy / CodeBuddy」。当前接入固定使用 `glm-5v-turbo`；实际服务可用性、模型和积分以服务商为准。
3. 同意发送预览图后开始对话。开发机上曾用红蓝测试图和公开人像验证看图及返回参数；其他电脑和账号仍需自行验证。

### 自备 API

在「设置」→「对话和看图」选择服务商，填写密钥和模型，保存并使用。密钥存入本机钥匙串。连接测试和看图测试分别判断连接与视觉能力：**连接成功不代表模型能看图**。API 和部分订阅按服务商规则计费。

## 配置 AI 改图

打开「设置」→「AI 改图」，选择服务并填写密钥、模型。回到「AI 改图」输入要求，选择作用范围，检查发送内容、服务和费用提示，再点击生成。生成效果与分辨率由服务商决定；真实服务是否可用需用自己的账号确认。应用不会将生成式改图等同于可还原的调色参数。

## 常见问题

**为什么设置中没有我的本机账号？** 确认相应 CLI 已安装，且可以从本机启动；安装后重新打开应用。显示已安装不等于登录或额度已验证。

**WorkBuddy 已登录，为什么仍不能用？** CodeBuddy CLI 可能需要单独登录；使用同一账号认证后再尝试。不同模型是否支持看图也需要分别核实。

**导入后照片会被自动修改吗？** 不会。只有你主动应用风格、调整参数或确认其他操作后，照片才会改变。

**更新在哪里？** 左下角版本入口可查看记录；左上角应用菜单有「检查更新」。自动下载安装流程尚未经过正式发行包的端到端验收。
